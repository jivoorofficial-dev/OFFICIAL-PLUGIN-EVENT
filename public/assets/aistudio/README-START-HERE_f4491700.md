# حزمة وثائق Tarbwy Event Manager

تحتوي الحزمة على: - `TARBWY-EVENT-MANAGER-SPEC.md`: المواصفات الفنية
المرجعية. - `AGENT-MASTER-PROMPT.md`: البرومبت الرئيسي لوكيل البرمجة.

## الاستخدام

1.  افتح مشروع WordPress في Antigravity أو بيئة الوكيل.
2.  أضف الملفين إلى مساحة العمل، مثلاً داخل `project-docs/`.
3.  أعطِ الوكيل محتوى `AGENT-MASTER-PROMPT.md` واطلب منه اتباعه.
4.  يجب أن يبدأ بفحص المشروع والبيئة، ثم يقدم خطة، ثم ينفذ ويختبر.
5.  استخدم Staging أولاً، ولا ترفع إلى الموقع الحي قبل النسخ الاحتياطي
    والاختبارات.

## معلومات لم تُسلّم بعد

الهوية البصرية، الشعار، التاريخ والمكان، نصوص الصفحة، استمارة التسجيل
النهائية، قائمة VIP، إعدادات SMTP وسياسة الخصوصية. يجب عدم اختراع هذه
المعلومات.

## قرارات أساسية

500 شخص إجمالاً بمن فيهم المرافقون؛ كل مرافق له سجل وQR مستقل؛ اللغة
العربية فقط؛ الاستضافة الحالية؛ الاتصال Online.
