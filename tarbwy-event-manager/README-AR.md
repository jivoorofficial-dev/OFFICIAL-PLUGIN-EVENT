# دليل التثبيت والإعداد — Tarbwy Event Manager (الإصدار 1.0.0)

**المشروع:** إدارة حفل إطلاق «تربوي — الاتحاد العربي للقيادة التربوية»  
**النطاق المستهدف:** `https://tarbwy.org`  
**اللغة والاتجاه:** العربية فقط — RTL بالكامل  
**السعة المعتمدة:** 500 شخص إجمالاً (شاملاً الضيوف الأساسيين والمرافقين)

---

## 1. المتطلبات الفنية للاستضافة

قبل رفع الإضافة وتفعيلها على بيئة الاختبار (Staging) أو بيئة الإنتاج (Production)، تأكد من توفر المتطلبات التالية على استضافة WordPress الحالية:

- **إصدار PHP:** `7.4` أو أحدث (مختبر ومتوافق مع PHP 7.4 و 8.0 و 8.1 و 8.2 و 8.3).
- **إصدار WordPress:** `6.0` أو أحدث.
- **قاعدة البيانات:** `MySQL 5.7+` أو `MariaDB 10.3+` مع محرك `InnoDB` (ضروري للأقفال الذرية ومنع تكرار الدخول المتزامن).
- **شهادة الأمان (HTTPS):** إلزامية لعمل كاميرا مسح رموز QR عبر متصفحات الهواتف والأجهزة اللوحية (`navigator.mediaDevices.getUserMedia`).
- **إعدادات البريد (SMTP):** وجود إضافة SMTP مفعلة ومربوطة بمزود البريد المعتمد من «تربوي» لضمان تسليم رسائل `wp_mail()`.

---

## 2. خطوات التثبيت على Staging أولاً ثم الإنتاج

> **تنبيه هام:** لا ترفع الإضافة إلى الموقع الحي (`tarbwy.org`) مباشرة قبل أخذ نسخة احتياطية كاملة (قاعدة البيانات + الملفات) وتجربتها على بيئة Staging أولاً.

### الخطوة 1: التثبيت عبر لوحة تحكم WordPress
1. قم بتحميل ملف الحزمة الجاهزة للتثبيت: `tarbwy-event-manager.zip`.
2. ادخل إلى لوحة تحكم WordPress (`wp-admin`).
3. انتقل إلى: **إضافات (Plugins) ← أضف جديداً (Add Plugin) ← رفع إضافة (Upload Plugin)**.
4. اختر الملف `tarbwy-event-manager.zip` واضغط **التثبيت الآن (Install Now)**.
5. بعد انتهاء الرفع، اضغط **تفعيل الإضافة (Activate Plugin)**.

### الخطوة 2: تحديث الروابط الدائمة (Permalinks)
عند تفعيل الإضافة، تقوم تلقائياً بتسجيل المسارات الأربعة الخاصة بالحدث وتفريغ قواعد التوجيه (`flush_rewrite_rules`). وللتأكد التام من عمل المسارات مع إعدادات خادم الويب (Apache/Nginx/LiteSpeed):
1. انتقل إلى **الإعدادات (Settings) ← الروابط الدائمة (Permalinks)**.
2. اضغط زر **حفظ التغييرات (Save Changes)** مرة واحدة دون تغيير هيكل الروابط الحالي للموقع.

## 3. المسارات الرسمية الأربعة للإضافة

بعد التفعيل، تصبح المسارات التالية جاهزة ومستقلة عن القالب الحالي دون أي تأثير على صفحات الموقع الأخرى:

| المسار | الوظيفة | مستوى الوصول |
| :--- | :--- | :--- |
| `/launch` | صفحة الهبوط الرسمية لحفل الإشهار + نموذج طلب الحضور العام | عام (مع حماية Honeypot و Rate Limiting) |
| `/launch/vip` | بوابة الدعوات الشخصية لكبار الشخصيات (VIP RSVP) | خاص (يتطلب رمز دعوة عشوائي مشفر SHA-256، لا يظهر في القوائم العامة) |
| `/launch/ticket` | صفحة عرض وطباعة بطاقة الدخول الفردية المزودة برمز QR | خاص لحامل التذكرة المؤكد (لا يعرض البريد أو الهاتف) |
| `/launch/checkin` | واجهة موظفي الاستقبال لمسح QR والبحث والتسجيل اليدوي | محمي بتسجيل الدخول وصلاحية `checkin_tarbwy_guests` |

كما توفر الإضافة Shortcodes اختيارية في حال رغب فريق المحتوى بتضمين الصفحة أو الاستمارة داخل صفحة Gutenberg أو Elementor:
- `[tarbwy_landing_page]`
- `[tarbwy_registration_form]`

## 4. إعداد Cron Job الحقيقي على الاستضافة لمعالجة البريد والتذكيرات

تعتمد الإضافة على جدولَي مهام مجدولة:
- `tarbwy_em_process_email_queue`: يعمل كل 5 دقائق لمعالجة طابور الرسائل وإعادة المحاولة التلقائية للرسائل المتعثرة (حتى 3 محاولات مع Exponential Backoff).
- `tarbwy_em_send_event_reminders`: يعمل كل ساعة لإرسال تذكير تلقائي للمؤكدين فقط قبل 24 ساعة من موعد انطلاق الحفل.

لضمان دقة المواعيد على الاستضافة، يُوصى بإضافة Server Cron Job حقيقي من لوحة الاستضافة (cPanel / Plesk) يعمل كل 5 دقائق:

```bash
*/5 * * * * wget -q -O - https://tarbwy.org/wp-cron.php?doing_wp_cron >/dev/null 2>&1
```

## 5. ما ينتظر استلامه من فريق «تربوي» لإدخاله من لوحة الإدارة

تم تصميم الإضافة بحيث لا تخترع أي بيانات غير مستلمة، ويمكن لفريق «تربوي» إدخال البيانات التالية مباشرة من قسم **فعاليات تربوي ← إعدادات الحدث**:
1. **التاريخ والوقت الرسمي لحفل الإشهار.**
2. **اسم الفندق/القاعة والعنوان التفصيلي ورابط الخريطة.**
3. **قائمة المتحدثين والبرنامج الزمني والشركاء.**
4. **قائمة مدعوي VIP بصيغة CSV** لاستيرادها عبر أداة المعاينة (Dry-Run).
5. **ربط إعدادات SMTP** الخاصة بنطاق `tarbwy.org`.
