# سجل الإصدارات والتغييرات — CHANGELOG.md

جميع التغييرات الجوهرية في إضافة **Tarbwy Event Manager** موثقة في هذا الملف.

---

## [1.0.0] — 2026-11-07 (الإصدار الإنتاجي الأول)

### المزايا المضافة (Added)
- **المعمارية وقاعدة البيانات:**
  - بناء إضافة WordPress مستقلة تحت Namespace `Tarbwy\EventManager`.
  - إنشاء 8 جداول `InnoDB` مخصصة باستخدام `$wpdb->prefix` و `dbDelta()` مع دعم الترقيات (`tarbwy_em_db_version`).
  - تطبيق قيود الفهرسة والـ `UNIQUE` على `ticket_id` في جدول `tarbwy_checkins` و `token_hash` في جدولي الدعوات والتذاكر.
- **الصفحات والمسارات المستقلة:**
  - `/launch`: صفحة هبوط عربية RTL متكاملة مع نموذج طلب الحضور العام ودعم المرافقين والـ Shortcodes.
  - `/launch/vip`: بوابة دعوات كبار الشخصيات المشفرة بـ `SHA-256` مع تأكيد مباشر أو اعتذار وإضافة مرافقين.
  - `/launch/ticket`: صفحة بطاقة الدخول الشخصية القابلة للطباعة بدون عرض أي بيانات اتصال حساسة.
  - `/launch/checkin`: بوابة موظفي الاستقبال المتوافقة مع الهاتف والتابلت لمسح QR والبحث والتسجيل اليدوي والإحصائيات الحية.
- **الأمان والصلاحيات:**
  - إضافة 6 صلاحيات دقيقة (`Capabilities`) و 3 أدوار وظيفية (`Event Administrator`, `Registration Manager`, `Check-in Staff`).
  - حماية النماذج العامة بـ Honeypot و Rate Limiting وكشف التكرار.
  - حماية تصدير CSV بعلامة `UTF-8 BOM` وتطهير الصيغ ضد `CSV Formula Injection`.
- **البريد الإلكتروني والجدولة:**
  - 10 قوالب بريد عربية RTL قابلة للتحرير مع طابور إرسال (`Queue`) وإعادة محاولة تلقائية (`Exponential Backoff`) عبر `WP-Cron`.
